# 일정캐치 (ScheduleCatcher)

문자 · 카카오톡 · 네이버 웍스 메시지에서 일정을 자동으로 찾아내고,
**저장 전에 항상 물어보는** 안드로이드 앱입니다.

```
[카톡] 김선생님: 내일 오후 3시 회의실 A에서 QA 회의 있습니다
          │
          ▼  (기기 안에서 분석)
┌────────────────────────────────────────────┐
│ 일정 감지: QA 회의                          │
│ 11월 5일 (목) 오후 3:00 · 어디에 저장할까요? │
│ [📅 캘린더]   [⏰ 알람]   [둘 다]            │
└────────────────────────────────────────────┘
   탭하면 → 제목/날짜/시간/장소/알람 시점 수정 후 저장
```

## 기능

| 기능 | 내용 |
|---|---|
| 메시지 감지 | 알림 접근 권한(NotificationListener)으로 카카오톡, 삼성/Google 메시지, 네이버 웍스 알림을 읽습니다. 다른 앱도 추가할 수 있습니다. |
| 한국어 날짜 인식 | `내일/모레/글피`, `다음주 화요일`, `11/12(목)`, `12월 3일`, `2026-11-30`, `3일 후`, `오후 2시~4시`, `14:00-16:00`, `10시 반`, `정오`, `PM 2:30` 등 |
| 저장 전 확인 | 알림의 **[📅 캘린더] [⏰ 알람] [둘 다]** 버튼, 또는 탭해서 내용 수정 후 저장 |
| 네이버 캘린더 | CalDAV(`caldav.calendar.naver.com`)로 바로 저장. 캘린더 자체 알림(VALARM)도 함께 설정 가능 |
| 알람 | 날짜 지정 가능한 앱 알람(잠금화면 표시, 5분 다시 알림, 재부팅 후 유지) 또는 기본 시계 앱 알람(24시간 이내) |
| 공유하기 | 감지되지 않은 메시지도 길게 눌러 **공유 → 일정캐치**로 보내면 확인 화면이 열립니다 |

### 감지 규칙
- `시간` + (`날짜` 또는 `일정 키워드`) → 일정으로 판단 (예: "내일 3시", "3시 회의")
- `날짜` + `일정 키워드` → 종일 일정 (예: "12월 24일 송년회")
- 이미 지난 시각, `1:1`, `1.8Gy`, `2시간` 같은 표현은 무시
- 오전/오후가 없으면 **1~6시는 오후**, 7시 이후는 그대로 (예: "7시 30분 컨퍼런스" → 오전 7:30)

## 개인정보 / 보안
- 메시지 분석은 **전부 기기 안에서** 이루어지며, 원문은 어디에도 전송·저장되지 않습니다.
- 네이버 캘린더로는 사용자가 저장을 누른 일정(제목/시간/장소)만 전송됩니다.
- **메시지 원문을 캘린더 메모에 넣는 옵션은 기본 꺼짐**입니다 (환자 정보 등 민감정보 보호).
- 애플리케이션 비밀번호는 Android Keystore 기반 암호화 저장소에 보관합니다.

## 설치

1. GitHub → **Actions** → `ScheduleCatcher Android` → 최신 실행 → **Artifacts**의 `ScheduleCatcher-debug-apk` 다운로드
2. 압축을 풀어 `app-debug.apk`를 휴대폰으로 옮겨 설치 (출처를 알 수 없는 앱 설치 허용 필요)
3. 앱을 열고 화면 안내대로 권한 허용
   - **알림 접근 허용** — Android 13 이상에서 "제한된 설정" 때문에 켜지지 않으면:
     설정 → 애플리케이션 → 일정캐치 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도
   - 알림 표시, 알람 및 리마인더, 전체 화면 알림
4. (선택) 삼성 휴대폰은 설정 → 배터리 → 백그라운드 사용 제한에서 일정캐치를 **절전 예외**로 두세요.

> CI 디버그 빌드는 실행마다 서명 키가 달라질 수 있어, 새 버전 설치 시 기존 앱 삭제가 필요할 수 있습니다.

## 네이버 캘린더 연결

1. 네이버 → 내정보 → 보안설정 → **2단계 인증** 사용
2. **애플리케이션 비밀번호 관리**에서 비밀번호 생성 (네이버 로그인 비밀번호가 아님)
3. 앱의 "2. 네이버 캘린더 연결"에 아이디 + 애플리케이션 비밀번호 입력 → **연결하고 캘린더 선택**

네이버 계정을 연결하지 않으면, [캘린더] 선택 시 기기의 캘린더 앱 "새 일정" 화면이 미리 채워진 상태로 열립니다.

## 프로젝트 구조

```
ScheduleCatcher/
├── core/   순수 Kotlin (Android 의존성 없음, JVM 단위 테스트)
│   ├── ScheduleParser.kt    한국어 날짜/시간/제목/장소 추출
│   ├── ICalendarBuilder.kt  iCalendar(RFC 5545) 생성
│   └── CalDavClient.kt      CalDAV 캘린더 탐색 + 일정 PUT (OkHttp)
└── app/    Android 앱
    ├── MessageListenerService  알림 읽기 → 파싱 → 감지 알림
    ├── Notifications           [캘린더] [알람] [둘 다] 알림
    ├── ConfirmActivity         확인/수정 화면 (공유 받기 포함)
    ├── QuickSaveActivity       알림 버튼 처리
    ├── ScheduleSaver           네이버 캘린더 / 알람 저장
    ├── AlarmScheduler/Receiver/RingActivity  날짜 지정 알람
    └── MainActivity            설정 · 권한 · 인식 테스트
```

### 빌드
```bash
./gradlew :core:test           # 파서 등 단위 테스트
./gradlew :app:assembleDebug   # APK (Android SDK 필요)
./gradlew -PcoreOnly=true :core:test   # Android SDK 없는 환경
```

## 한계
- **iPhone은 지원하지 않습니다.** iOS는 다른 앱의 알림/메시지를 읽는 API를 제공하지 않습니다.
  (iOS에서는 단축어 앱으로 '공유 → 캘린더 추가' 정도만 가능)
- 카카오톡은 알림에 보이는 내용만 읽을 수 있습니다. 카톡 설정에서 **알림 메시지 미리보기**가 켜져 있어야 합니다.
- 일정이 여러 메시지로 나뉘어 오면(예: "내일 3시" / "QA 회의") 날짜/시간이 있는 메시지 기준으로 감지되며 제목은 확인 화면에서 수정하세요.
- 기본 시계 앱 알람은 Android 표준 인텐트가 "시:분"만 지원해서 24시간 이내 일정에만 사용합니다.
