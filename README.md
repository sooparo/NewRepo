# 🍚 우리집 식단

아침·저녁 **주간 식단 추천** → **장보기 목록 자동 생성** → **쿠팡에서 바로 검색/주문**까지 이어지는 휴대폰용 웹앱(PWA)입니다.
4인 가족(어른 2 + 6세·4세 아이) 기준 분량으로 맞춰져 있어요.

## 주요 기능

| 탭 | 기능 |
|---|---|
| 📅 식단 | 월~일 아침·저녁 자동 추천 · 끼니별 🔄다른 메뉴 / 📋직접 고르기 / 🍽외식 표시 · 전체 새로 추천 |
| 🛒 장보기 | **요일별 메뉴** 화면(요일 → 끼니 → 메뉴 → 재료, 다른 날에도 쓰는 재료 🔁 표시) + 종류별 합산 화면 · ✓구매 체크 · ✕빼기 / 다시 넣기 · 직접 넣기(`우유 1L`) · 매주 고정 항목 · 카톡 공유 |
| 📖 레시피 | 레시피 80개 + 밀키트 16종 검색 · ❤️즐겨찾기(더 자주 추천) · 🚫제외(추천 안 함) |
| ⚙️ 설정 | 양식 횟수, 밀키트 횟수, 매운 요리 횟수, 평일/주말 조리 시간 · 백업/복원 |

### 추천 규칙
- **아침**: 토스트·시리얼·요거트·주먹밥 등 간단 메뉴. 평일은 15분 이내, 주말은 핫케이크·죽 같은 메뉴도 추천. 빵/밥/시리얼 종류가 연달아 나오지 않게 섞음
- **제철 과일**: 그달 제철 과일 3종을 3·2·2일씩 배정 (장보기 품목 수 줄이기). 포도·방울토마토 등은 4세 목 걸림 주의 팁 표시
- **저녁**: 한식 위주 + 양식 주 2회(설정 가능). 한식은 메인 + 국·찌개, 한 그릇 요리(카레·비빔밥 등)는 국 없이
- **밀키트**: 바쁜 평일 저녁에 주 2회(설정 가능) 배치. 밀푀유나베·불고기전골·짜장면·궁중떡볶이처럼 아이와 먹기 좋은 한식 12종 + 함박·찹스테이크·감바스 등 양식 4종. 끼니마다 ‘밀키트로 ↔ 직접 요리로’ 전환 가능
- 일주일 안에 메뉴 중복 없음, 이틀 연속 같은 단백질(소/돼지/닭/생선…) 피함
- 매운 요리는 주 1회까지(설정 가능)이며 **아이 몫 덜어두는 방법**을 같이 안내
- 이미 고른 메뉴와 **재료가 겹치는 메뉴를 우대** → 장볼 거리가 줄어듦

## 쿠팡 연동 방식

쿠팡은 **소비자 장바구니에 자동으로 담는 공개 API를 제공하지 않습니다.** 매크로로 담는 방식은 약관 위반과 계정 제한 위험이 있어서, 이 앱은 다음 방식을 씁니다.

1. 장보기 목록의 **`쿠팡`** 버튼 → 해당 재료로 쿠팡 검색 결과가 열림
2. 마음에 드는 상품을 쿠팡 앱에서 **공유 → 링크 복사** → 앱에서 품목 이름을 눌러 붙여넣고 저장
3. 다음 주부터는 **`⭐쿠팡`** 버튼이 그 상품 페이지로 바로 열림 → '장바구니 담기'만 누르면 끝

## 휴대폰에 설치

배포된 주소를 휴대폰에서 연 다음:
- **아이폰(Safari)**: 공유 버튼(□↑) → **홈 화면에 추가**
- **안드로이드(Chrome/삼성인터넷)**: ⋮ 메뉴 → **홈 화면에 추가 / 앱 설치**

데이터는 그 휴대폰 브라우저에 저장됩니다(서버 없음). 휴대폰을 바꾸기 전에는 설정 → 백업 파일 저장을 해 두세요.

## 배포

빌드 과정이 없는 정적 사이트라서 파일을 그대로 올리면 됩니다.

- **GitHub Pages**: `master`에 push하면 `.github/workflows/pages.yml`이 테스트 후 배포합니다.
  저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다.
  (비공개 저장소에서 Pages를 쓰려면 GitHub 유료 플랜이 필요합니다. 무료로 쓰려면 저장소를 공개로 바꾸거나 Netlify / Cloudflare Pages에 이 저장소를 연결하면 됩니다.)

## 개발

```bash
npm test          # 추천 규칙·장보기 합산 테스트 (node --test)
npm start         # http://localhost:8080 에서 미리보기
```

| 파일 | 내용 |
|---|---|
| `js/data/recipes.js` | 레시피 데이터: 메뉴를 추가하거나 고칠 때 여기만 수정 |
| `js/data/fruits.js` | 제철 과일 (월, 하루 양, 아이 주의사항) |
| `js/planner.js` | 주간 추천 로직 |
| `js/shopping.js` | 재료 합산, 수량 표시, 쿠팡 링크 |
| `js/app.js` | 화면 / 이벤트 |
| `sw.js` | 오프라인 캐시. **파일 수정 후 `VERSION`을 올려야** 설치된 앱에 반영됨 |
